# v2.0.5 release notes

Release repository: https://github.com/D4gkan/Steam-Desktop-Authenticator-2.0

## Highlights

- Add desktop QR account export on Windows and Linux for transfer to SDA Mobile.
- Compress QR transfers and omit session credentials for reliable phone-camera scanning.
- Keep Android imports compatible with legacy plaintext `.maFile` QR payloads.
- Display a clear warning because exported QR data contains the full Steam Guard secret in plaintext.
- Publish versioned Windows x64, Linux x64, and Android release builds.
- Update desktop and Android application versions to 2.0.5.

## Notes

This release primarily adds safer QR-based account transfer between the desktop app and the Android companion app. The QR payload is compressed and stripped of session information to make camera scanning more reliable, while remaining compatible with older plaintext import payloads.

The release also includes explicit warnings that exported QR data still contains the full Steam Guard secret in plaintext, so users should treat exported QR payloads as sensitive material.
